# Pressure Test

A structured critical thinking tool for evaluating beliefs, decisions, and conclusions.

Capture a proposition. Triage it. Pressure-test it with three questions. Decide what to do with it.

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build    # Output in dist/
```

## Test

```bash
npx vitest run   # All tests
npx vitest       # Watch mode
```

## Tech

- React 18 + TypeScript
- Vite
- localStorage (no backend)
- Vitest + React Testing Library

## Data

All data stays in your browser's localStorage. Export anytime as JSON from the dashboard.
